# UI 优化设计规范：方案 B（更大胆重构）

**日期**：2025-05-11  
**目标**：在 v2.0 基础上做更全面的 UI 更新，采用精炼深色风格

---

## 1. 设计原则

### 1.1 精炼深色
- 减少装饰特效（去掉过度的发光、扫描线、光晕）
- 更克制的光影效果
- 更大留白，更清晰的视觉层级
- 去掉噪点纹理覆盖层，保持纯净

### 1.2 保持识别度
- 保留现有配色系统（cyan/amber/emerald/violet/rose）
- 保留 spring 动画风格（但速度略快、更克制）
- 保留现有功能架构

---

## 2. 主窗口设计

### 2.1 顶部导航
- **样式**：改为 segmented control 风格
- **容器**：Tab 放在一个有背景的容器中（`rgba(255,255,255,0.03)`）
- **选中状态**：深色背景（`#141418`），cyan 文字
- **未选中**：灰色文字（`#5a5a66`），透明背景

### 2.2 概览页卡片
- **主卡片**：今日 Token 卡片有视觉强调
  - 渐变背景：`linear-gradient(135deg, rgba(0,212,255,0.08), rgba(0,212,255,0.02))`
  - 顶部边框：`2px solid rgba(0,212,255,0.3)`
  - 增加趋势信息：如 "↑ 18% vs 昨日"（emerald 色）
- **其他卡片**：保持简洁，背景 `rgba(255,255,255,0.03)`
- **内边距**：从 20px 增加到 24px（更透气）

### 2.3 统计页
- 图表容器：更清晰的分割，更大的内边距
- 数据表格：优化排序指示，增加空状态

### 2.4 设置页
- 表单分组：用分组标题和分割线
- 每个设置项：有更清晰的说明文字
- 开关样式：优化视觉
- 操作按钮：更清晰的分组

### 2.5 通用组件
- **Toast**：优化位置（更靠上一点），动画更流畅
- **骨架屏**：更好的加载状态
- **空状态**：友好的空状态设计，带图标和引导文字

---

## 3. 悬浮窗设计

### 3.1 尺寸调整
- 从 `320x140` 调整为 `320x150`
- 内容区域内边距从 `14px 19px` 调整为 `16px 20px`

### 3.2 布局调整
- **左侧主区域**：今日 Token 更大更突出
- **右侧指标区**：5分钟 / 累计 上下排列
- **图表区**：保持 sparkline，但优化高度

### 3.3 视觉风格
- 毛玻璃效果保留但更克制
- 去掉扫描线、光晕 orb、边缘旋转光效
- 保留玻璃反射，但减弱
- 背景透明度保持 `0.48`

### 3.4 交互优化
- 点击主卡片 → 打开主窗口概览页
- 点击右侧指标 → 打开主窗口统计页
- 右键菜单 → 优化分组，更清晰的分隔

## 4. 视觉系统调整

### 4.1 颜色微调
```css
/* 保持现有变量，调整使用方式 */
:root {
  --bg: #0a0a0e;
  --surface: rgba(255,255,255,0.03); /* 更淡 */
  --surface-hover: rgba(255,255,255,0.05);
  --border: rgba(255,255,255,0.06);
  --text: #eaeaf0;
  --text-secondary: #a1a1aa;
  --text-muted: #5a5a66;
  
  /* 强调色保持不变 */
  --cyan: #00d4ff;
  --amber: #ffb347;
  --emerald: #2dd4a8;
  --violet: #a78bfa;
  --rose: #f43f5e;
}
```

### 4.2 阴影简化
```css
/* 更克制的阴影 */
--shadow-card: 
  0 1px 2px rgba(0,0,0,0.2),
  0 1px 0 rgba(255,255,255,0.02) inset;

--shadow-hover: 
  0 4px 12px rgba(0,0,0,0.25);
```

### 4.3 动画调整
```css
/* 更快、更克制的动画 */
--ease-spring: cubic-bezier(0.34, 1.4, 0.64, 1); /* 略软一点 */
--transition-fast: 150ms;
--transition-normal: 250ms;
```

### 4.4 圆角保持
- 面板：14px
- 卡片：12px
- 按钮：8px/10px
